## 阶段与验收

- [x] 第一阶段：正确性止血。编辑补发取历史路由与当前匹配结果的交集；共享过滤器读取失败不降级；条件配置严格校验；补回归测试。
- [~] 第二阶段：统一求值与决策记录。统一编译、解释、有限条件分组、匹配范围；固定共享配置快照；持久化版本化决策并接入消息详情；保留期与有界记录。
- [ ] 第三阶段：配置与页面。过滤器只读详情、引用清单、修改历史、统计与记录；专用条件编辑器；草稿、真实消息、历史样本测试及新旧对比；Flow 全链路模拟与真实拓扑展示。
- [ ] 第四阶段：媒体类型与性能治理。统一媒体类型，版本化编译缓存，批量解析；补端到端回归、编译、构建与运维说明。

## 必须保持的语义

- 旧条件数组按 AND 解释；默认仍为正文子串匹配，不静默增加文本规范化。
- 串联过滤为 AND、并联路径为 OR；命中即停仅在 Flow 产生目标后生效。
- 配置解析或求值失败不放行；历史路由不是当前过滤授权。
- 历史记录与当前重评分开，旧消息没有历史决策时显示“未记录”。
- 预演不保存、不入队、不发送、不调用外部 AI；重试旧任务与按当前配置重新评估是不同操作。
- 每次求值固定配置快照；日志不输出消息正文、凭证或敏感链接，详情记录有大小与保留期限制。
- 数据库变更使用新增 goose migration，保留旧条件行为，不修改已执行 migration。
